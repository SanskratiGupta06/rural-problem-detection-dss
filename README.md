# Rural Problem Detection and Decision Support System

A bilingual (English / Hindi) web application that helps identify
village-level problems and supports decision-making for rural development.

## Features
- English and Hindi language toggle
- Light and dark theme
- Interactive demo and explorer sections
- Works fully in the browser, no installation or server needed
- Data is saved locally in the user's browser

## Live Demo
https://SanskratiGupta06.github.io/rural-problem-detection-dss/

## How to Run Locally
1. Download `index.html`
2. Open it in any modern browser

## Tech Stack
HTML, CSS and JavaScript (single file, no external dependencies)
